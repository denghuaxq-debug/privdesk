==================================================
  B/C 电脑：设置代理上外网（配合 PrivDesk 共享上网）
==================================================

现在用的是 HTTP 代理, Windows 系统设置就能直接用, 大多数情况不用装任何插件!

前提: A 那台(能上外网的)已在 PrivDesk 里点了"开启共享上网", 你拿到了这段配置:
      类型: HTTP 代理
      地址: 你的服务器IP
      端口: 6080
      账号: xxxx
      密码: xxxx


==================================================
  方法一：Windows 系统代理（推荐, 什么都不用装）
==================================================
让整台电脑(浏览器和多数软件)都走外网:

1. 打开: 设置 → 网络和 Internet → 代理
2. 找到"手动设置代理" → 点"设置/编辑"
3. 打开"使用代理服务器"开关
4. 地址填:  你的服务器IP        端口填:  6080
5. 保存
6. 打开浏览器访问任意外网页, 会弹窗要"用户名/密码",
   填 账号 / 密码, 勾"记住凭据"即可。

不想用了: 回到这里把"使用代理服务器"关掉, 立刻恢复本地上网。

⚠️ 注意: 开了系统代理后, 访问国内网站也会绕经服务器, 可能变慢;
   A 那台关机后要记得来这里关掉代理, 否则会上不了网(关掉即恢复)。


==================================================
  方法二：只代理浏览器（用 ZeroOmega 插件, 本文件夹已带）
==================================================
只想让浏览器走外网、其它软件照常走本地, 用这个更干净。

【Chrome / Edge】
  1. 把本文件夹的  ZeroOmega解压版_Chrome-Edge  文件夹拷到电脑, 放固定位置别删。
  2. 地址栏输入 chrome://extensions (Edge: edge://extensions) 回车
  3. 打开右上"开发者模式"
  4. 点"加载已解压的扩展程序" → 选那个文件夹 → 确定
  5. 出现 O 图标即成功(提示要停用就点"保留")
  6. 点 O 图标 → 选项 → 新建情景模式(如 waiwang, 类型"代理服务器"):
       代理协议:  HTTP        ← 注意选 HTTP, 不要选 SOCKS!
       代理服务器: 你的服务器IP
       代理端口:  6080
     → 应用选项。第一次上网页弹窗填 账号 / 密码。
  7. 用: 点 O 图标选 waiwang; 停: 点 O 图标选"[直接连接]"

【Firefox】
  1. about:addons → 右上齿轮 → "从文件安装附加组件" → 选 ZeroOmega_Firefox.xpi
  2. 之后同上, 协议选 HTTP。


==================================================
  重要：为什么协议要选 HTTP, 不选 SOCKS?
==================================================
Chrome/Edge 内核不支持"带密码的 SOCKS 代理"(会报
"不支持 socks 代理认证")。所以这里统一用 HTTP 代理, 它支持账号密码,
上网页完全够用。填代理时协议一定选 HTTP。


==================================================
  验证有没有生效
==================================================
设好后浏览器打开:  https://ifconfig.me  或百度搜"ip"
显示的公网 IP 变成 A 那台的 IP → 成功。


==================================================
  连不上怎么办
==================================================
1. A 那台的 PrivDesk 还开着吗?"共享上网"是绿色开启状态吗?
2. 服务器安全组放行 6080 的 TCP 了吗? (最常见的坑)
3. 地址/端口/账号/密码填错没? 协议是不是选成 SOCKS 了(要选 HTTP)?
4. A 那台没关机吧? A 一关 B/C 就用不了。
