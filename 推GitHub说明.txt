==================================================
  在新电脑上把 PrivDesk 推到 GitHub (操作说明)
==================================================

这个包里带着完整的 git 记录和已配好的 GitHub 远程地址。
你只要在一台能正常登录 GitHub 的电脑上, 解压后跑一条命令即可。


--------------------------------------------------
零、新电脑需要先装 Git
--------------------------------------------------
· Windows: 去 https://git-scm.com/download/win 下载安装 (一路下一步即可)
· Mac:     终端运行  git --version  , 没装会自动提示安装
装完后, 用"Git Bash"(Windows) 或"终端"(Mac) 来跑下面的命令。


--------------------------------------------------
一、解压
--------------------------------------------------
把本压缩包解压, 会得到一个文件夹 (里面有一个隐藏的 .git 目录和本说明)。
※ Windows 解压后若看不到 .git, 是因为它是隐藏文件夹, 不影响, 命令照跑。


--------------------------------------------------
二、进入文件夹并还原代码
--------------------------------------------------
在 Git Bash / 终端里, cd 进解压出来的文件夹, 然后执行:

   git reset --hard HEAD

这一步会把所有源码文件从 git 记录里还原出来 (解压时可能只有 .git)。


--------------------------------------------------
三、推送到 GitHub
--------------------------------------------------
   git push -u github master

· 第一次会让你登录 GitHub:
  - 若弹出浏览器窗口 → 点登录/授权即可
  - 若命令行要账号密码:
      用户名: denghuaxq-debug
      密码:   不是登录密码! 要填 Personal Access Token (令牌)
              生成: GitHub 网页 → 右上头像 → Settings → Developer settings
                    → Personal access tokens → Tokens (classic) → Generate new token
                    勾选 "repo" 权限 → 生成 → 复制那串字符当密码粘贴

· 看到 "master -> master" 就是推成功了。


--------------------------------------------------
四、推成功后, 在网页上出 Mac 安装包
--------------------------------------------------
1. 打开 https://github.com/denghuaxq-debug/privdesk
2. 点上方 "Actions" 标签
   (若提示要启用 Actions, 点 "I understand my workflows, enable them")
3. 左侧选 "Build macOS (.dmg)" → 右边 "Run workflow" 按钮 → 绿色 Run workflow
4. 等几分钟 (变绿勾 = 成功), 点进那次运行记录
5. 页面最下方 "Artifacts" 里有 "PrivDesk-macOS-dmg", 下载解压就是 .dmg

完成! dmg 即可发给客户安装。
