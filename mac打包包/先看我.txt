==================================================
  PrivDesk · Mac 打包包  ——  先看我
==================================================

这个文件夹里有把 PrivDesk 打成 Mac 安装包(.dmg)所需的一切。
你只要在一台 Mac 上跑一下脚本即可,无需 Apple 开发者账号。


--------------------------------------------------
怎么用 (最稳的方式: 用终端跑, 别双击)
--------------------------------------------------
1. 把收到的压缩包解压, 得到 PrivDesk 文件夹。

2. 打开"终端": 按 Command+空格, 输入 Terminal 回车。

3. 在终端里先输入 bash 和一个空格 (bash 后面必须有空格!):

      bash

   先不要回车! 然后把本目录下的「一键打包.command」文件
   用鼠标直接拖进终端窗口 —— 它会自动补上完整路径, 最后按回车。

   完整效果类似:  bash /Users/你/Downloads/PrivDesk/mac打包包/一键打包.command

   ※ 为什么不直接双击:
     从 Windows 压缩过来的脚本会丢失"可执行"标记, 双击时 Mac 会报
     "已损坏 / 来自身份不明的开发者"。用上面 bash 的方式可绕过, 最稳妥。

4. 按屏幕提示等待。第一次会装 Rust 和依赖, 比较慢(约 10~30 分钟,
   取决于机器和网速)。完成后:

   👉 安装包在  PrivDesk/dist-mac/  目录里, 文件名形如 PrivDesk_1.0.0_universal.dmg


--------------------------------------------------
这台 Mac 需要先具备 (脚本装不了的)
--------------------------------------------------
✅ 必须: Node.js  —— 去 https://nodejs.org 下 LTS 版双击安装, 或终端 brew install node
✅ 联网  —— 脚本要联网装 Rust 编译器和 npm 依赖 (这是 Mac 专用的, 没法提前塞进包里)

以下脚本会自动处理, 你不用管:
  · Xcode 命令行工具 (没装会自动唤起安装窗口)
  · Rust 编译器 (没装会自动装)
  · frp 的 Mac 二进制 (已随包预置在 frp预置/ 里, 不用联网下)


--------------------------------------------------
打出来的包怎么发给客户 / 怎么装
--------------------------------------------------
· dist-mac/ 里的 .dmg 就是成品, 发给客户即可。
· 此包未做苹果签名, 客户首次打开需"右键(按住 Control 点击) → 打开"。
· 完整使用方法见  发布/Mac端使用说明.txt (也在 PrivDesk 文件夹里)。
