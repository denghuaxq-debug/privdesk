连接组件被安全软件拦截

PrivDesk 的连接功能被系统或安全软件拦截了。这是远程工具的常见误报(并非病毒),请按下面任一方法放行后重试:

Windows 智能应用控制
设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 智能应用控制 → 选择"关闭"
360 / 火绒 / 电脑管家
打开杀毒软件 → 找到拦截记录 / 信任区 → 把 PrivDesk 添加为"信任"或"允许运行"
Windows Defender
Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 → 添加 PrivDesk 安装目录

放行后,回到 PrivDesk 重新点击"连接"即可。

macOS 拦截了 PrivDesk 的连接组件。这是未签名应用的常见情况(并非病毒),请按下面方法放行后重试:

首次打开被拦("已损坏 / 无法验证开发者")
在"访达 → 应用程序"里找到 PrivDesk,按住 Control 键点击图标 → 打开,在弹窗里再点"打开"即可。
仍打不开(提示"已损坏")
打开"终端",粘贴执行:
xattr -dr com.apple.quarantine /Applications/PrivDesk.app
然后重新打开。
系统设置里放行
系统设置 → 隐私与安全性 → 拉到底,看到 PrivDesk 被阻止 → 点"仍要打开"。

放行后,回到 PrivDesk 重新点击"连接"即可。

怎么远程别人的电脑

先让对方在他的电脑上装好 PrivDesk 并连接成功, 他会得到一个远程地址发给你。你在上面填好即可。

对方是 Mac
对方需开启"系统设置 → 通用 → 共享 → 屏幕共享", 并设一个 VNC 密码。你选"Mac", 填对方给的地址和这个密码。
对方是 Windows
对方需开启远程桌面(他的 PrivDesk 里有"一键开启")。你选"Windows", 填对方给的地址, 点开始后在弹出的窗口里输入对方的用户名和开机密码。

连不上多半是: 对方还没连线 / 服务器安全组没放行那个端口 / 地址填错。

对方怎么设置代理

这是 HTTP 代理, 在需要上外网的电脑上按下面填 (用你复制给他的那段配置):

Windows 系统代理 (最简单, 免装)
设置 → 网络和 Internet → 代理 → "手动设置代理"打开 → 地址填服务器IP、端口填代理端口 → 保存。第一次上网页会弹窗要账号密码, 填上勾"记住"即可。
只想代理浏览器
Chrome/Edge 装扩展 "ZeroOmega"(离线包已备) → 新建情景 → 协议选 HTTP → 服务器填服务器IP、端口填代理端口 → 应用。弹窗时填账号密码。
手机
Wi-Fi 设置里给当前网络配置 HTTP 代理: 服务器填服务器IP、端口填代理端口, 用到账号密码时填上。

连不上多半是: 服务器安全组没放行该端口 / 这台出口电脑没开着 / 账号密码填错。
